# Documents pour NotebookLM

Un document par fichier de code, pour faire une vidéo explicative de chacun. Chaque document contient le code
complet (recopié automatiquement depuis le vrai fichier, avec ses numéros de ligne), l'explication ligne par
ligne, de vrais exemples tirés du projet, les pièges, les questions d'examinateur et leurs réponses.

| Document | Fichier expliqué |
|---|---|
| `01_download.md` | `nutri/download.py` |
| `02_clean.md` | `nutri/clean.py` |
| `03_tools.md` | `nutri/tools.py` |
| `04_garde_fou.md` | `nutri/garde_fou.py` |
| `05_agent.md` | `nutri/agent.py` |
| `06_evaluation.md` | `nutri/evaluation.py` |
| `07_tests.md` | le dossier `tests/` |

## Mode d'emploi
1. Créer **un carnet NotebookLM par fichier**, et y importer **un seul** document : la vidéo reste centrée sur ce
   fichier.
2. Dans le Studio, choisir **Résumé vidéo**, puis **Personnaliser**, et coller la consigne ci-dessous.

## Consigne à coller pour la vidéo
> Explique ce fichier de code à une étudiante débutante en Python qui doit le présenter à l'oral demain : un
> examinateur peut choisir n'importe quelle fonction au hasard et lui demander de l'expliquer ligne par ligne.
> Suis l'ordre du document, morceau par morceau. Pour chaque morceau, montre le code, dis à quoi il sert, explique
> les lignes importantes avec des mots simples, et donne l'exemple concret tiré du projet. Insiste sur les pièges
> et termine par les questions d'examinateur avec leurs réponses. En français.
